How quality is verified

Generation-time schema gating → deterministic structural validation (declared tools/arguments only, strict role alternation) → 3-gram Jaccard ≥ 0.85 de-duplication against all shipped lots → independent LLM scoring → final review. The deterministic stage is public and reproducible (evaluation/).

New lots are audited (hash, ID, 3-gram Jaccard) against previously shipped lots, so no budget is spent twice on the same row.
